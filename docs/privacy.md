# Privacy and safety

- The module has one LSPosed scope: `com.netease.uuremote`.
- It does not request network, storage, accessibility, overlay or root permissions.
- Theme settings are stored in libxposed Remote Preferences.
- No UU account, remote host, frame contents, credentials or screenshots are sent anywhere by the module.
- Debug evidence must be kept outside the public repository and redacted before sharing.
- Disabling or uninstalling the module leaves the UU APK and user data untouched.
